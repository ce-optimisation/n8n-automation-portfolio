Using the dashboard from your phone (securely)

  1. Set a strong DASHBOARD_PASSWORD in .env and restart. Without a password the dashboard only answers on this PC.
  2. Recommended — Tailscale (free): install Tailscale on this PC and your phone, sign in to both with the same account, then on the PC run tailscale serve --bg 8765. Open the https://<pc-name>.<tailnet>.ts.net address on your phone. Traffic is encrypted, nothing is exposed to the internet, and the app can stay bound to 127.0.0.1.
  3. Home Wi-Fi only (simpler, unencrypted): set CLIPENGINE_HOST=0.0.0.0, allow the Windows Firewall prompt for Private networks only, and open the address printed in the console. Only do this on a network you trust.

Never port-forward this dashboard on your router or expose it on a public network.
