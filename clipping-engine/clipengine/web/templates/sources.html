How it works

  1. Authorise. A source is checked automatically only when you have declared that automated retrieval is permitted: either its site is listed in ALLOWED_URL_DOMAINS, or a written permission is recorded below. Platforms whose terms forbid automated access (e.g. {{ restricted[:5]|join(', ') }}) additionally need the platform's written permission.
  2. Add the verified feed, live-stream or channel address and say who authorises it.
  3. Check now. The first check only notes what is already published (the “baseline”) — it does not download the back catalogue. From then on, every new item is imported automatically, and a live stream is recorded while it is on air.
  4. Older items (optional). To bring in earlier recordings, use “Import older items” on the source, or set “Import existing items on first check” when adding it. Every item is imported at most once.
  5. Imported recordings are transcribed, clipped and placed in Ready to Review.

Nothing logs in, uses cookies, or bypasses paywalls/DRM. A source that cannot be authorised can still be used manually: save its episode link on the Import page and attach a file supplied by the rights holder. The PC must be on and awake for monitoring to run.
