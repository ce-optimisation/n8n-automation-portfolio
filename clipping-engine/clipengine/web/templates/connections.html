A destination is VERIFIED only when the platform's own API reports the exact account id recorded for it. One shared administrator login never lets one brand reach another brand's account. Delivery is OFF for every destination until you switch it on for that one account. Each switched-on destination starts in drafts / private mode (Facebook Reel draft, YouTube private); you can switch one destination to PUBLIC mode (type PUBLISH), after which clips you approve are published there. Platforms can still hold a public upload back (Facebook posts from an app in development mode may be visible only to app roles; YouTube lifted its private-only rule for unaudited projects on 2 Nov 2026) and every result says what really happened. Instagram has no draft step: an Instagram destination sends only in PUBLIC mode, which needs INSTAGRAM_PUBLIC_PUBLISH on {% if ig_public %}(it is ON: switch each Instagram destination on, then type PUBLISH){% else %}(it is OFF){% endif %}.
