Set up in four steps

One email per finished recording, with thumbnails, durations, opening quotes and links to your private dashboard. No video files are attached. Nothing is ever sent until you complete step 3; until then notifications are prepared and held ({{ held }} held now).

  1. Where to send.
    Saved only in your local .env. {% if not s.dashboard_url %}Links will only work on this PC until Phone access is set up.{% endif %}
  2. Connect a sending account. Currently: {{ 'Microsoft Graph (Outlook.com)' if transport == 'graph' else 'SMTP (' ~ (s.smtp_host or 'no server') ~ ')' }} — {% if not mailer.configured %}not set up{% elif mailer.connected %}connected{% if mailer.account %} as {{ mailer.account }}{% endif %}{% else %}not signed in{% endif %}. Choose one of the two supported ways:
    Option A (quickest, about 3 minutes): send from a Gmail account

    The email still arrives in your Outlook inbox; Gmail is only the sender. This needs no developer registration. (Outlook.com itself no longer accepts password or app-password sign-in for sending, so an Outlook address cannot be used this way.)

    1. In a browser open myaccount.google.com/apppasswords and sign in to the Gmail account (2-Step Verification must be on; Google offers to turn it on).
    2. Type the name Clipping Engine, press Create, and copy the 16-letter password Google shows.
    3. Paste it below and press Save. It is stored in: {{ token_backend }} — not in any file you upload.
    {% if smtp_password_saved %}

    Any other provider that offers SMTP with an app password works the same way (enter its server and port).

    Option B: send from your Outlook.com account (Microsoft sign-in)

    Microsoft only lets an application send mail for you if it has an Application (client) ID. Creating one is free, but a personal Outlook.com account must first have an Azure “directory”, and Microsoft asks for a payment card to verify identity when creating it (nothing is charged for this). If you prefer not to do that, use Option A.

    1. Only if you have never used Azure: open azure.microsoft.com/free, press Try Azure for free and sign in with your Outlook.com account. (Skip this if step 2 already shows a “New registration” form.)
    2. Open entra.microsoft.com → App registrations → New registration. Name: Clipping Engine. Supported account types: Personal Microsoft accounts only. Leave Redirect URI empty. Press Register.
    3. On the app's page: Authentication → Allow public client flows → Yes → Save.
    4. On Overview, copy the Application (client) ID and paste it here. (There is no secret to create or store.)
